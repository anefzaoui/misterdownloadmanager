Each file is one of the theme's icons, unchanged, renamed to the need MDM uses it for
(crates/app/src/themeicons.rs lists them):
- 16/<need>.png: Adwaita/16x16/<context>/<icon>.png, a colour picture.
- 24/<need>.svg: Adwaita/scalable/<context>/<icon>.svg, a colour drawing (drawn at 24 pixels
  and up).
- 16/ and 24/<need>-symbolic.svg: Adwaita/symbolic/<context>/<icon>-symbolic.svg, a one-colour
  icon; MDM draws its greys in the theme's text colour as it reads it, as GNOME does.

MDM's own, drawn for MDM in Adwaita's style and colours (GPL-3.0-or-later, as MDM), where
Adwaita has no icon of that meaning, at 16, 24, 32 and 48 pixels: ft-pdf (a page with a "PDF"
label) and ft-torrent (a page with a magnet), colour pictures (<need>.png), and ui-to-tray (a
window going down to the notification area), a one-colour picture (ui-to-tray-symbolic.png)
drawn in the theme's text colour. Any can be swapped for another file of the same name.
