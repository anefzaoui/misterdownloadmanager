The Aero theme's icon set (#45).

MDM's own: pictures drawn for Mister Download Manager in the manner of Windows Vista's and Windows 7's desktop icons (2006-2009): glass, a light top
half, chrome. Not one of
Microsoft's icons, or any other project's, is used or copied. GPL-3.0-or-later, as MDM (its
LICENSE, at the top of the repository).

Each file is a colour picture named for the need MDM uses it for (crates/app/src/themeicons.rs
lists them), at four sizes: 16/<need>.png, 24/, 32/ and 48/ (a screen at 100 % to 300 %). Any
can be swapped for another file of the same name.

The title bar's Minimize, Maximize, Restore and Close are drawn by the theme's title bar itself
(crates/app/src/winui.rs); every other need has a picture here.
