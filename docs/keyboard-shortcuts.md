# Keyboard shortcuts

[← Back to docs index](README.md)

The same list is in MDM under **Help → Keyboard shortcuts**, and the menus show each command's
keys beside it. On a Mac, **⌘** (Command) takes the place of **Ctrl**: **⌘N** adds a download.

## Adding and finding

| Keys | What they do |
|---|---|
| **Ctrl+N** | Add a download (**Add URL**) |
| **Ctrl+F** | Find a download |
| **F3** | Find the next match |
| Type a name | Jump to the download whose name starts with it |

## The selected download

| Keys | What they do |
|---|---|
| **Enter** | Open the selected download (a double-click follows right-click → **On Double click**) |
| **Alt+Enter** | **Properties** of the selected download |
| **Ctrl+M** or **F2** | Move or rename the selected download |
| **Shift+F10** | Open the selected download's menu |
| **Delete** | Delete the selected downloads (asks first) |
| **Shift+Delete** | Delete the selected downloads and their files (asks first) |

## Selecting

| Keys | What they do |
|---|---|
| **Ctrl+A** | Select all downloads |
| **Ctrl+click** | Select or unselect one more download |
| **Shift+click** | Select every download up to this one |
| Drag on blank space | Select the downloads in the box |
| **Up** / **Down** | Select the previous / next download |
| **Shift+Up** / **Shift+Down** | Make the selection longer or shorter |
| **Ctrl+Up** / **Ctrl+Down** | Move without changing the selection |
| **Ctrl+Space** | Select or unselect the download with the dotted outline |
| **Page Up** / **Page Down** | Move a page up / down |
| **Home** / **End** | Select the first / last download |

## Menus and windows

| Keys | What they do |
|---|---|
| **F10**, or **Alt** pressed alone | Open the first menu (**Tasks**); on a Mac **Ctrl+F2** |
| **Alt** + a menu's underlined letter | Open that menu (Windows and Linux) |
| **Up** / **Down** | Move through an open menu |
| **Left** / **Right** | The menu before / after; in a submenu, **Left** closes it |
| **Enter**, or an item's underlined letter | Run the highlighted item |
| **Esc** | Close a menu or dialog (an open drop-down list first) |
| **Enter** | In **Download File Info**: **Start Download** |

Right-click any text box for **Cut**, **Copy**, **Paste**, **Delete** and **Select all**.

In the Scheduler's time boxes, **Up** / **Down** and the number keys change the selected part of the time, and **Left** / **Right** move between parts.
