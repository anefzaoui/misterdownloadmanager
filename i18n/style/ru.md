- Use the infinitive for commands, menu items, and action buttons. In instructions to the user, use the polite plural imperative. (Открыть; Приостановить)
- Phrase check box labels as concise actions or conditions, usually with an infinitive; make clear what enabling the box does. (Запускать при входе в Windows; Показывать уведомления)
- Address the user formally as «вы» when needed. Keep the tone neutral and helpful; omit the pronoun when Russian grammar allows. (Выберите файл; Не удалось подключиться к серверу)
- Write confirmation questions clearly and name the action or object. Avoid vague questions such as «Вы уверены?». Use action-specific buttons. (Удалить этот файл?; Удалить)
- Keep labels and column titles short and use noun phrases. Russian has no articles; omit unnecessary prepositions and verbs. (Имя; Размер)
- Use concise status wording. For ongoing actions, use a noun or an impersonal construction; for counts, provide the correct Russian plural form. (Проверка…; Загружается 1 файл / 2 файла / 5 файлов)
- Keep error fragments grammatical when combined with a detail. Prefer an impersonal construction and identify the object when it helps the user. (Не удалось открыть файл: {error})
- Write event log entries as brief, informative statements. Use a past-tense form that agrees with the named item, or an impersonal construction. (Файл загружен.; Не удалось возобновить загрузку.)
- Use sentence case: capitalize the first word and proper names, not every word in a heading. Write months and weekdays in lowercase. (Параметры загрузки; понедельник, 14 мая)
- Use a period for complete sentences, but not for labels, headings, buttons, or short status fragments. Use an ellipsis for an action that is still in progress, with no preceding space. (Загрузка завершена.; Загрузка…)
- Use Russian angle quotation marks «…» in prose when quotation marks are necessary. Avoid putting UI labels in quotes unless distinguishing them from surrounding text. (Откройте раздел «Параметры».; Выберите «Папка назначения».)
- Follow Russian spacing conventions: put a space between a number and a unit or percent sign, and use a nonbreaking space where the layout supports it. (25 МБ; 100 %)
- Let the verb or participle agree with its stated subject. If the subject is omitted, use a natural impersonal construction rather than a form that suggests the wrong subject. (Загрузка завершена.; Не удалось сохранить файл.)
- Use natural Russian word order. Keep a variable beside the word it qualifies, and place error details after a colon when they are supplemental. (Скорость загрузки: {speed}; Не удалось открыть файл: {error})
- Prefer established Russian technical terms. Use a borrowed word only when it is familiar and clearer than a Russian alternative; do not invent transliterations. (браузер; сервер)
- Use «скачать» or «загрузка» for receiving a file, and describe sending a file to a server as «отправка», so the two directions are not confused. (Скачать файл; Отправка файла на сервер)
- Use «Параметры» for configurable app or system options, in line with Windows terminology. Use «диалоговое окно» for a dialog window. (Открыть параметры; Диалоговое окно выбора папки)
- Use short, consistent action labels for download controls: «Приостановить» suspends an operation, «Остановить» ends it, and «Возобновить» continues it. (Приостановить загрузку; Остановить)
- Distinguish checking a value or condition from testing a feature. Use «проверить» for verification and «протестировать» for trying a feature. (Проверить ссылку; Протестировать новую функцию)
- Avoid English-style title capitalization and unnecessary abbreviations. If a short form is needed, use a standard Russian abbreviation consistently. (История загрузок; МБ)
