- Commands, buttons, and action menu items use a concise, polite imperative ending in “-வும்”. Use the same wording for the same action wherever it appears. (பதிவிறக்கத்தைத் தொடங்கவும்; கோப்பை நீக்கவும்)
- Checkbox labels name an option or state; do not phrase them as commands or questions. (பதிவிறக்கம் முடிந்ததும் கணினியை அணைக்கவும்; தானாகத் தொடங்கு)
- Do not address the user directly unless needed. When direct address is necessary, use the respectful “நீங்கள்”; keep the register clear and courteous. (கடவுச்சொல்லை உள்ளிடவும்; நீங்கள் தேர்ந்தெடுத்த கோப்புறை)
- Phrase confirmation prompts as direct, neutral questions. Name the action or item so the choice is clear. (இந்தப் பதிவிறக்கத்தை நீக்க வேண்டுமா?; பதிவிறக்கங்களை நிறுத்த வேண்டுமா?)
- Keep labels and column titles brief and telegraphic. Omit articles and sentence-style wording; use a noun or a compact noun phrase. (கோப்பு பெயர்; பதிவிறக்க வேகம்)
- Use a concise present-progressive form for activity statuses. Preserve placeholders exactly and include the item being acted on when it helps clarity. (சரிபார்க்கிறது…; {n} கோப்புகள் பதிவிறக்கப்படுகின்றன)
- Keep error fragments concise and preserve the colon and any error placeholder. Do not add a subject that is absent from the source. (திறக்க முடியவில்லை: {error})
- Write event-log entries as brief, complete records, usually with the event in the past tense. Keep timestamps and separators unchanged. (10:32 — பதிவிறக்கம் நிறைவடைந்தது.)
- Tamil has no uppercase or lowercase. Do not impose English title case on Tamil headings; capitalize English product names only as officially written. (பதிவிறக்க அமைப்புகள்; Windows 11)
- Use Tamil names for months and weekdays. Do not capitalize them; follow the source format for dates and times. (திங்கள்; ஜனவரி)
- Use Tamil punctuation consistently. Do not put a space before punctuation; use one space after it when the sentence continues. Use the ellipsis character for a continuing status. (பதிவிறக்கம் முடிந்தது.; சரிபார்க்கிறது…)
- Use curly double quotation marks around quoted text when needed. Do not add quotation marks to ordinary interface labels. (“பதிவிறக்கம் முடிந்தது” என்ற செய்தி; அமைப்புகள்)
- Tamil often omits an understood subject. Make the verb agree with the stated or implied subject, and avoid adding “நீங்கள்” to status messages. (பதிவிறக்கம் நிறுத்தப்பட்டது.; கோப்புகள் பதிவிறக்கப்படுகின்றன.)
- Use natural Tamil word order, generally placing the object before the verb. Keep placeholders in a position that reads naturally without changing their spelling. (கோப்பைத் திறக்க முடியவில்லை; {n} கோப்புகளைப் பதிவிறக்கவும்)
- Prefer established Tamil equivalents. Retain or transliterate a loanword only when it is familiar or needed for a technical concept; use it consistently. (கோப்புறை; கோப்பு ஹோஸ்டிங் சேவை)
- Preserve variables, format specifiers, and other non-translatable tokens exactly. Do not change their braces, order, or spelling. ({error}; {n})
- Use sentence-ending punctuation for complete messages, but omit it from short labels, button text, and column headings. (பதிவிறக்கம் நிறைவடைந்தது.; பதிவிறக்க வேகம்)
