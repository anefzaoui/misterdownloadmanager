<!-- How Italian writes Mister Download Manager: sent with every translation request in this language (lingo.style). Learned from reviews in 071cdd90, 78422c2a, f4b4cdc4; a person checks every rule. -->
- Write instructions, buttons, checkboxes, tooltips and error hints in the informal second-person imperative (tu). Never use the infinitive or the formal imperative. (Digitare il nome della categoria -> Digita il nome della categoria; il server è occupato ({status}); riprovare più tardi -> il server è occupato ({status}); riprova più tardi)
- Address the user as 'tu'. Render 'Are you sure you want to…?' as 'Vuoi davvero …?', not a bare infinitive question. Short confirmation questions without 'Are you sure' may stay as an infinitive question. (Eliminare "{name}" dall'elenco… -> Vuoi davvero eliminare "{name}" dall'elenco…; Ripristinare {names} come in origine…? (kept infinitive))
- Keep the definite article in labels, checkboxes, menu commands and titles. Do not use telegraphic style without articles. (Personalizza tasti per impedire… -> Personalizza i tasti per impedire…; Usa impostazioni di sistema -> Usa le impostazioni di sistema)
- Join noun + noun compounds in titles and labels with 'di' plus the article. Do not juxtapose the nouns. (Proprietà categoria -> Proprietà della categoria; Lettura elenco file... -> Lettura dell'elenco dei file...)
- Ongoing progress and status texts: when the text is only an action noun, add 'in corso' before the trailing '...'. Otherwise use 'action noun + di + object...'. Keep the ellipsis. (Verifica... -> Verifica in corso...; Avvio... -> Avvio in corso...)
- Render 'X could not be …' / 'X failed' errors as 'Impossibile + infinitive + X'. Do not use 'X non è stato …'. ({file} non è stato aperto: {error} -> Impossibile aprire {file}: {error}; la connessione protetta non è riuscita -> impossibile stabilire la connessione protetta)
- Make adjectives and participles agree with the Italian noun they refer to, even when English gives no clue. (molto più lento delle altre connessioni -> molto più lenta delle altre connessioni; visualizzato nell'elenco delle code -> visualizzata nell'elenco delle code)
- Category, legend and list labels standing for groups of items take the plural. (Compresso -> Compressi; Pronto: {list} -> Pronti: {list})
- Write month and weekday names in lowercase, as Italian requires. (Gennaio -> gennaio; Lunedì -> lunedì)
- For a sequence of steps use 'poi' (or 'e'), not 'quindi'. Clicking a button is written as 'fai clic su X'. (Installa 7-Zip (gratuito), quindi fai clic… -> Installa 7-Zip (gratuito), poi fai clic destro…; …scegli un file .torrent, quindi Cerca. -> …poi fai clic su Cerca.)
- Use 'restare' rather than 'rimanere' for things that stay as they are. (I suoi file rimangono dove sono. -> I suoi file restano dove sono.; rimangono invariate -> restano invariate)
- Natural Italian word order: put 'ancora', 'prima', 'ora' and 'per ora' before the verb or noun phrase, not at the end. (Nessun indirizzo ancora -> Ancora nessun indirizzo; Metti in pausa il download prima -> Prima metti in pausa il download)
- Keep 'its/their' possessives that the English uses ('suoi', 'il suo'). Drop a redundant 'tuo' in front of 'sistema'/'browser'. (Sposta i download in Generali -> Sposta i suoi download in Generale; con il gestore di pacchetti del tuo sistema -> con il gestore di pacchetti del sistema)
- Say 'finestra', not 'finestra di dialogo'. Name the window descriptively instead of quoting its button. (Non mostrare più questa finestra di dialogo -> Non mostrare più questa finestra; Mostra la finestra di dialogo Avvia download -> Mostra la finestra di avvio del download)
- Render 'X needed' / 'this needs X' as 'Serve X' / 'Serve un…'. Do not use 'X necessario' or 'richiede'. (7-Zip necessario -> Serve 7-Zip; {service}: questo richiede un account premium -> {service}: serve un account premium)
- Render 'again' actions in event log entries as a noun phrase with 'Nuovo/Nuova'. Render 'Checked/Done' results with 'completata'. (Download di nuovo dall'inizio -> Nuovo download dall'inizio; Verificato: {have} di {total} presenti -> Verifica completata: presenti {have} di {total})
- Use the future for what will happen after the current step. Use the present for a current refusal or state; do not translate 'won't' as a future. (riprende quando è di nuovo attiva -> riprenderà quando sarà di nuovo connessa; {service} non fornirà questo file -> {service} non fornisce questo file)
- Rephrase literal English constructions into idiomatic Italian. Spell out implicit subjects ('it' = the proxy, the adapter, the download) instead of 'esso'. Keep the text concise. (Ogni connessione passa attraverso di esso, da {ip}. -> Ogni connessione passa da questa scheda, con indirizzo {ip}.; Passa al download il cui nome inizia con esso -> …il cui nome inizia così)
- Keep spacing exactly as in the source: double spaces before placeholders, and spaces around '/' when the English has them. (Ad esempio: {address} -> Ad esempio:  {address}; Seleziona il primo/ultimo download -> Seleziona il primo / l'ultimo download)
- Keep '\n' line breaks and rebalance them so the lines have similar length in Italian. Never merge the lines into one. (…un archivio diviso (.part1.rar, .7z.001) una volta che… (one line) -> …(.part1.rar, .7z.001) quando\ntutti i volumi sono presenti…)
- Mnemonics: keep exactly one '&'. Put it on the first letter of the key Italian word, or on the letter of the original English shortcut when the same letter is available. (Arre&sta coda -> &Interrompi coda; &Download video -> Download &video)
- Use sentence-style lowercase inside menu items and labels. Lowercase common nouns such as 'web' and 'referer'. (Per St&ato -> Per s&tato; Per &pagina Web padre -> Per pagina &web di origine)
- Lowercase fragments that are inserted after another message stay lowercase, even when they start with 'impossibile'. (Impossibile avviare i torrent: {error} -> impossibile avviare i torrent: {error})
- Plural forms: when the number is in a placeholder, drop articles that would imply the singular, and make participles agree with the count. (Eliminare anche il file {n} dal disco -> Elimina anche {n} file dal disco; {listed} di {total} video elencati (singular form) -> {listed} di {total} video elencato)
- Use abbreviated units and key names as Italian keyboards and UIs show them. Write 'byte' in lowercase. ({h} ora/e {m} min -> {h} h {m} min; ({bytes} Byte) -> ({bytes} byte))
