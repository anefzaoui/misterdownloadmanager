- Use formal address. Prefer wording that does not address the user directly; where an instruction is needed, use the formal imperative. Avoid tegező forms and unnecessary Ön. (Adja meg a letöltési helyet.; Válassza ki a mappát.)
- Phrase commands as clear actions, usually with a formal imperative. Keep button labels short; use an established concise action label where one exists. (Válassza a Mentés lehetőséget.; Mégse)
- Use concise action names for menu commands, keeping the wording consistent with related buttons. (Letöltés szüneteltetése; Összes kijelölése)
- Use a noun or short noun phrase for a check box label. Do not add a full instruction or terminal punctuation. (Értesítés a letöltés befejezésekor; Automatikus indítás)
- Phrase confirmation prompts as polite, direct questions. Include the action and its object so the consequence is clear. (Biztosan le szeretné állítani a letöltést?; Törli a kijelölt fájlt?)
- Use short noun phrases for labels and column titles. Omit articles and prepositions unless they are needed for natural Hungarian. (Fájlnév; Letöltés állapota)
- Write progress and status messages as concise, natural Hungarian phrases. Use an ellipsis only when the operation is still in progress. (Ellenőrzés…; {n} fájl letöltése folyamatban)
- Make error messages read naturally as complete Hungarian phrases; do not copy English fragment structure if it sounds unnatural. (Nem sikerült megnyitni: {error}; A fájl nem található.)
- Write event log entries as brief, neutral statements, normally in the past tense. Use a period for a complete sentence. (A letöltés elindult.; A fájl letöltése befejeződött.)
- When the subject is implied, choose a verb form that agrees with the implied subject. Recast the sentence if the subject or number is unclear. (A letöltés szünetel.; A letöltések befejeződtek.)
- Use natural Hungarian word order, placing information in the order that makes the message easiest to understand. Reorder placeholders when needed, and do not attach Hungarian suffixes directly to placeholders. (A(z) {file} letöltése nem sikerült.; A(z) {folder} mappában)
- Use sentence case for UI text: capitalize the first word and proper names, not every word in a title. Hungarian month and weekday names are lowercase. (Letöltési beállítások; március 15., hétfő)
- Follow Hungarian punctuation conventions: no space before punctuation and one space after it. Use Hungarian quotation marks when quotation marks are needed. (Hiba történt: {error}; „Letöltés kész”)
