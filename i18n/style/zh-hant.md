- 命令、按鈕與功能表項目使用精簡的動作詞或動詞片語；同一動作在各處用詞一致，不加句號。 (Download → 下載; Pause → 暫停)
- 核取方塊標籤描述啟用後的選項或狀態，簡潔明確；不要寫成對使用者的指令。 (Start automatically → 自動啟動; Play a sound when complete → 完成時播放音效)
- 以「您」稱呼使用者，採親切、清楚、尊重的語氣；避免過度正式或口語化。 (您可以在此變更下載位置。; 請選取要下載的檔案。)
- 確認提示直接說明即將執行的動作及其影響，以「嗎？」結尾；避免含糊的「是否」句式。 (要刪除此下載項目嗎？; 確定要停止所有下載嗎？)
- 欄位標籤與欄標題採精簡名詞或名詞片語，不加冠詞；能省略的介詞及完整句式一律省略。 (File name → 檔案名稱; Download folder → 下載資料夾)
- 進度與狀態訊息使用自然、易掃讀的完整短語；進行中的動作用「正在」，並保留變數及其位置。 (Checking... → 正在檢查…; {n} downloading → 正在下載 {n} 個檔案)
- 錯誤片語先寫結果，再以全形冒號引出錯誤細節；保留錯誤變數，不自行改寫其內容。 (Could not be opened: {error} → 無法開啟：{error})
- 事件記錄採簡短、客觀的陳述；主詞可省略，已完成的動作用「已」標示。 (Download added → 已新增下載項目。; Connection lost → 連線已中斷。)
- 中文沒有大小寫；中文標題不套用英文標題式大小寫。英文產品名稱與縮寫依官方寫法保留大小寫。 (Download settings → 下載設定; Windows 11 → Windows 11)
- 月份與星期使用中文數字名稱，日期格式保持自然易讀；月份與日期間留空格。 (June 12, Wednesday → 6 月 12 日，星期三)
- 使用全形中文標點，包括逗號、句號、冒號與問號；進度省略號使用單一字元「…」，不要用三個半形句點。 (下載已完成。; 正在連線…)
- 中文引號使用「」；引用介面文字時只標示必要範圍，不以引號包住一般按鈕或欄位標籤。 (請在「設定」中選取資料夾。; 找不到「下載」資料夾。)
- 中文與英文、數字或變數相鄰時保留適當空格；不要在中文標點與相鄰文字間多加空格。 (Windows 11 下載管理員; 已下載 3 個檔案)
- 狀態或命令中主詞通常可省略；動詞須與省略的主詞及時態語意相符，不要為了補齊英文句型而加入「它」或「您」。 (Paused → 已暫停; Download failed → 下載失敗)
- 依中文習慣安排語序：時間、地點或條件置於動作前；避免照搬英文的修飾語順序。 (Download to this folder → 下載至此資料夾; Start after download completes → 下載完成後啟動)
- 優先使用臺灣繁體中文中慣用的譯名；只有在沒有自然、通用譯法時才保留外來詞，產品名稱與必要縮寫除外。 (folder → 資料夾（不用「文件夾」）; URL → URL)
- 保留格式化標記、變數與其大小寫；依中文語序調整句子時，不翻譯或拆分標記。 (Saved to {folder} → 已儲存至 {folder}; Error: {error} → 錯誤：{error})
