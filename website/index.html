In short

Mister Download Manager (MDM) is a free, open-source download manager for Windows 10 and 11, with experimental builds for macOS and Linux. It looks and works like Internet Download Manager (IDM), but it is free (GPL-3.0), downloaded a 1 GiB file 5.4 times faster than IDM 6.42 in our published benchmark, and also downloads torrents, magnet links and videos from web pages. A browser extension for Chrome, Edge, Brave, Opera, Vivaldi and Firefox hands downloads to it.

From download to your first file.

One installer and one click in your browser. No account, no setup wizard to fight, nothing to learn if you've used a download manager before.

  1. Install, pick your language

    Download the installer for your computer and run it. It asks your language and connects your browsers.

  2. Keep browsing

    Click a download link as usual: the extension hands it to MDM. Over a video, a Download video button appears.

  3. Or paste an address

    Copy a link anywhere and MDM opens the download window, ready to go. Magnet links and .torrent files too.

  4. Watch it fly

    Eight connections at once, up to 32. Pull the plug and it carries on where it stopped.

How it works

Every connection at once

The first request reaches the server milliseconds after your click, and every connection opens together. When one finishes, it takes over half of the slowest piece.

Learns each server

A server that only allows two connections gets two, and MDM remembers it. In our benchmark IDM opened 480 against the same server and still finished later.

Your browsers, connected

Tick the browsers whose downloads MDM should take over. The extension hands them over with their cookies, so files behind a sign-in still work. Copied links open the download window too.

A few things to know before you start.

Is it really free?

Yes. It's open source under the GNU GPL, version 3. No trial, no paid edition, no registration key, no nag screen, no ads. More

Is it IDM?

No. It's an independent project with no connection to Tonec Inc. It's written from scratch in Rust and contains none of IDM's code or artwork. The layout follows the classic download manager because that's what many people know and like. More

Is it safe to install?

The whole source is public, and every release is built from it on GitHub's servers. No adware, no spyware, no bundled offers. The helpers it downloads for video are verified before they run. More

Can I move my downloads over from IDM?

Yes: export your list from IDM, then choose Tasks → Import → From IDM export file in MDM. More

Which browsers work with it?

Chrome, Edge, Brave, Opera and Vivaldi through the extension; Firefox is in testing. Without the extension, copy a link and MDM opens the download window. More

Mac or Linux?

Yes, to try: every release has a .dmg for Apple Silicon and Intel Macs and an AppImage, .deb, .rpm and .tar.gz for Linux, marked experimental while they mature. More

Where can I get help?

The user guide covers every window, with step-by-step tutorials. Something broken? Open an issue on GitHub, or use Help → Report a problem in the app.
