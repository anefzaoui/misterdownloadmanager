In short

Mister Download Manager (MDM) is a free, open-source download manager for Windows 10 and 11, with experimental builds for macOS and Linux. It looks and works like Internet Download Manager (IDM), but it is free (GPL-3.0), downloaded a 1 GiB file 5.4 times faster than IDM 6.42 in our published benchmark, and also downloads torrents and magnet links and videos from web pages. A browser extension for Chrome, Edge, Brave, Opera, Vivaldi and Firefox hands downloads to it.

The engine

Every connection, visible.

A file is split across eight connections the moment the server says it can, up to 32 if you like. When one finishes its part, it takes half of the biggest piece still left, so nobody waits on a straggler. The bar shows it happening, connection by connection.

  • Crash-safe resume. Progress is written as it goes; pull the plug and it carries on where it stopped, checking the server's file hasn't changed.
  • Expired links refreshed. When a download address times out, give it a fresh one and keep the data.
  • HTTP, HTTPS, FTP and FTPS, through proxies, SOCKS and PAC scripts.
  • Checksums. Give it an MD5, SHA-1, SHA-256, SHA-512 or CRC32 and it verifies the file when it lands.

In your browser

Click a link. MDM takes it from there.

The MDM extension hands every download to the app with its cookies and referrer, so files behind a sign-in still work. Point at a video and a Download video button appears over it: one click and MDM lists every quality. Drag the button where you like; it stays there on that site.

  • Right-click any link and choose Download with Mister Download Manager.

Torrents, built in

Pick the files. Skip the rest.

Paste a magnet link or open a .torrent and you get the real folder tree, with a checkbox at every level. Then it downloads next to everything else, with its peers, trackers and pieces one tab away. When it's done it stops sharing, like any download — unless you'd rather it kept going. No second program, no ads, no bundled offers.

Video from a page

Paste the page. Pick the quality.

Give it a video page, or click the button over the video, and it lists every quality the site offers, up to 4K at 60 fps, with sizes. The best picture and sound are merged into one MP4 for you.

  • Thousands of sites, powered by yt-dlp, downloaded on first use and checked against its developers' signing key before it ever runs.
  • ffmpeg (an LGPL build) is fetched only if you want merged qualities, and checked against its published checksums.
  • No DRM. Paid streaming services stay off limits, by design.

One list for everything

Web or torrent. Find it in a click.

Every row says where it came from: Web or Torrent. Every column has a filter, like a spreadsheet: tick the states you want to see, or type part of a name.

  • Sorted the way you think. Newest first, biggest first, fastest first: click a header.
  • Queues and a scheduler. Start at night, stop at seven, shut the PC down when the queue is done.
  • Speed limits. Per download or for everything, so calls and games stay smooth.

Benchmarks

IDM vs MDM, timed to the millisecond.

Seven downloads, each run at least seven times by both apps, from the same lab server on the same machine. The server's own log says when each request arrived and when the last byte left; nothing relies on either app's word. Every run is a dot.

IDM takes about three seconds to accept a download from its command line before it sends anything; downloads caught by its browser extension skip that step. That is why "Transfer" is the fair engine-to-engine view. "End to end" is here too.

How it was measured
  • Server. The lab server from this repository, on 127.0.0.1, serving generated content. It throttles, delays, refuses or cuts connections per scenario, and logs every request with millisecond start and end times.
  • Clients. IDM and MDM, both at default settings (8 connections), each given the download through the same documented command line: /d URL /p folder /f name /n. Both save to the drive that holds IDM's temporary folder, so neither pays a cross-drive copy.
  • Timing. End to end: from issuing the command to the finished file under its final name, polled every millisecond on a monotonic clock. MDM renames its finished file into place; IDM creates the final file early and fills it, so for IDM the moment it reaches full size counts. Transfer: the server's first request to its last byte, read on the same clock through a calibration request before each run.
  • Fairness. The apps alternate, IDM first on even runs and MDM first on odd ones, so drift on the machine hits both. One warm-up run each is discarded. Failed runs are counted, not dropped. Before every run the harness waits until the loopback is quiet: no closed connections to the server still lingering and a new connection made at once. Against a server that refuses extra connections IDM retries about 250 times a second, leaving thousands of closed sockets for half a minute; without the wait, whichever app ran next was timed on that backlog.
  • Statistics. Medians with interquartile ranges, bootstrap 95% intervals (10,000 resamples) for each median and for the ratio of medians, and a two-sided Mann–Whitney U test.
  • Limits. A loopback link has no real distance or packet loss; the faults stand in for them. Results are from one machine. Run it yourself: python tools/bench/bench.py, then python tools/bench/report.py.

Questions

Is it really free?

Yes. It's open source under the GNU GPL, version 3. No trial, no paid edition, no registration key, no nag screen, no ads. More

Is it IDM?

No. It's an independent project with no connection to Tonec Inc. It's written from scratch in Rust and contains none of IDM's code or artwork. The layout follows the classic download manager because that's what many people know and like. More

Is it safe to install?

The whole source is public, and every release is built from it on GitHub's servers. No adware, no spyware, no bundled offers. The helpers it downloads for video are verified before they run. More

Can I move my downloads over from IDM?

Yes: export your list from IDM, then choose Tasks → Import → From IDM export file in MDM. More

Which browsers work with it?

Chrome, Edge, Brave, Opera and Vivaldi through the extension; Firefox is in testing. Without the extension, copy a link and MDM opens the download window. More

Mac or Linux?

Yes, to try: every release has a .dmg for Apple Silicon and Intel Macs and an AppImage, .deb, .rpm and .tar.gz for Linux, marked experimental while they mature. More
