The browser extension

It hands your browser's downloads to MDM with their cookies, adds Download with Mister Download Manager to the right-click menu and puts a Download video button over videos. It comes with the app, in its extension folder, and on its own:

  • Chrome, Edge, Brave, Opera and Vivaldi (.zip: unzip, then Load unpacked on the browser's extensions page with Developer mode on)
  • Firefox (.xpi, in testing)

Store listings for Chrome, Edge and Firefox are on the way and will make this one click. The step-by-step guide shows each browser.

Install in three steps

  1. Download setup.exe above and run it. Windows may ask whether to allow it: the installer isn't code-signed yet, so choose More info → Run anyway.
  2. Pick your language and keep Set up browser integration ticked.
  3. Start Mister Download Manager from the Start menu, then download your first file.

What you need

  • Windows 10 or 11, 64-bit; about 100 MB of disk space.
  • macOS 11 or later on Apple Silicon or Intel (experimental).
  • Linux on x86-64 with a desktop session (experimental).
  • For video pages, MDM downloads yt-dlp (and ffmpeg if you want merged qualities) on first use.

Check your download

Every release lists the SHA-256 checksum of each file in SHA256SUMS.txt. On Windows, compare it with certutil -hashfile file SHA256; on macOS and Linux with shasum -a 256 file. All files are built from the public source by GitHub Actions; the build logs are on GitHub.

Older versions and source code

Every release, with its notes and files, is on GitHub Releases. The source code is at github.com/anefzaoui/misterdownloadmanager under the GNU GPL, version 3.
