The browser extension

It hands your browser's downloads to MDM with their cookies, adds Download with Mister Download Manager to the right-click menu and puts a Download video button over videos.

Firefox (and Zen, LibreWolf): one click from its add-ons store, and Firefox keeps it up to date.

Chrome, Edge, Brave, Opera and Vivaldi: one click from the Chrome Web Store, and the browser keeps it up to date. Edge first asks to allow extensions from other stores.

Can't use a store? It comes with the app, in its extension folder, and as its own download for Chromium browsers (.zip: unzip, then Load unpacked on the browser's extensions page with Developer mode on). The step-by-step guide shows each browser.

Install in three steps

  1. Download setup.exe above and run it. Windows may ask whether to allow it: the installer isn't code-signed yet, so choose More info → Run anyway.
  2. Pick your language and keep Set up browser integration ticked.
  3. Start Mister Download Manager from the Start menu, then download your first file.

With WinGet, Windows' package manager: in a terminal, the first line installs MDM and the second updates it.

winget install AhmedNefzaoui.MisterDownloadManager
winget upgrade AhmedNefzaoui.MisterDownloadManager

On Linux or a Mac

Linux: install the .deb with sudo apt install ./<file>.deb (Debian, Ubuntu, Mint) or the .rpm with sudo dnf install ./<file>.rpm (Fedora), and the packages bring what MDM needs. Or make the AppImage executable (chmod +x) and run it. MDM connects itself to your browsers at each start; then add the extension from your browser's store, above. More in the help.

macOS: open the .dmg and drag Mister Download Manager to Applications, then right-click it and choose Open the first time.

Linux won't be experimental any more. GNOME, KDE Plasma, Xfce and Cinnamon were checked window by window, with the tray and Dark Mode support, in Wayland sessions too, and the .deb and .rpm in clean Ubuntu 24.04, Debian 12 and Fedora 45 systems. What's left: the Flatpak Firefox isn't checked yet, and screen readers (Orca) don't read MDM's windows on Linux yet. macOS stays experimental. Windows, Mac and Linux

What you need

  • Windows 10 or 11, 64-bit; about 100 MB of disk space.
  • macOS 11 or later on Apple Silicon or Intel (experimental).
  • Linux on x86-64 with a desktop session, X11 or Wayland (today's files experimental).
  • For video pages, MDM downloads yt-dlp (and ffmpeg if you want merged qualities) on first use.

Check your download

Every release lists the SHA-256 checksum of each file in SHA256SUMS.txt. On Windows, compare it with certutil -hashfile file SHA256; on macOS and Linux with shasum -a 256 file. All files are built from the public source by GitHub Actions; the build logs are on GitHub.

Older versions and source code

Every release, with its notes and files, is on GitHub Releases. The source code is at github.com/anefzaoui/misterdownloadmanager under the GNU GPL, version 3.
